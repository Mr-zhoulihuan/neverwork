# NeverWork UI 设计规范 v3

> 纯 Rust + GPUI 桌面 IDE。本文是设计交付：设计稿（HTML/PNG）+ 设计令牌 + 组件清单 + 实现映射。
> 设计稿文件：`design/nw-main-v3.html`（v3 主界面，含多 Agent 协作 / 远程工作区 / 同步）、`design/nw-onboarding.html`（欢迎 + 设置）。

---

## 0. v3 新增的三项核心能力（架构级）

用户新增三条需求，已体现在 v3 设计稿中。它们不是纯 UI 需求，会重塑架构：

### 0.1 远程连接开发
- IDE 可连到远端机器（ssh/自建服务）开发：代码、编译、运行都在远端，本地是 UI。
- **架构影响**：后端 `workspace/agent/editor/terminal` 必须能作为 **Workspace Server** 独立运行；UI 通过 **远程协议**（建议 gRPC over WebSocket 或自定义 TCP + 序列化）连接。
- **UI 落点**：左栏顶部"工作区连接卡"——显示当前连接的远端名、地址、延迟、在线状态，可"切换"。

### 0.2 家里 / 办公室工作同步 —— **第一期不做**
- 产品目标是两端继续同一份工作与会话。
- **与 0.1 合流**：两端连同一个 Workspace Server 即天然同步（服务端为中心）。
- **v4 决策（用户拍板）**：**第一期先不开发同步策略**。远程连接（0.1）做，跨设备同步作为后续版本。
- **UI 落点**：`已同步` 指示、设备标识等**第一期弱化或标"即将推出"**；不建独立同步协议。

### 0.3 一个会话里多 Agent 工作流 —— **角色可自定义**
- 同一会话内多 Agent 协作；**角色不是固定的规划/编码/审查，而是用户可自定义**。
- 一个"团队"= 一组角色，可设：角色名、类型、模型、系统提示词/职责、身份色、技能、顺序。
- **编排模式**：流水线（A→B→C 顺序转交）/ 并行（同时跑）/ 主管指派（lead 动态分派）。
- **架构影响**：会话模型升级为**多 Agent 编排**——每个 Agent 有角色/身份/上下文，可 handoff、可并行，结果汇入同一会话流。
- **UI 落点**：见 `nw-agent-team.html`（Agent 团队编辑器）+ 主界面 v3 的协作流。
  - 顶部**协作流横幅**：按团队编排显示各角色当前步骤。
  - 消息**按角色身份色着色**（颜色自定义）。
  - **转交卡片**（居中胶囊）、**并行执行指示**。
  - 右侧文件树**标注文件由哪个角色产出**。
  - 输入框可切换"团队/工作流"。
  - **Agent 团队编辑器**（新增页面）：左侧团队列表、右侧角色卡（可拖拽排序/编辑/复制/删除）+ 编排模式选择 + 角色编辑面板（名称/类型/模型/提示词/身份色）。

## 1. 设计理念

- **Agent 优先，而非编辑器优先**：三栏中右侧 AI 是"并肩协作"，不是附属面板。
- **深色原生质感**：对齐 VSCode/Zed 的专业用户审美，低饱和、高可读。
- **安静但有焦点**：用单一强调色（蓝）引导注意力，语义色只用于状态。
- **本地优先的气质感**：密钥、代码都不外传，UI 文案明确传达。

## 2. 布局（三段式，可拖拽）

**v2 修订：Agent 对话居中作主舞台，文件树移到右侧。**

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏：红黄绿灯 + NeverWork — 项目名 + 状态 + ⌘K/⚙         │
├──────────┬──────────────────────────────┬────────────────┤
│ 左栏 230 │ 中栏（弹性，对话主舞台）        │ 右栏 300（文件） │
│          │                              │                │
│ Logo     │ 会话标题 + 模型选择            │ 文件/改动/预览   │
│ 模式切换  │ 对话流（宽 760 居中）          │ 当前路径         │
│ 会话列表  │  · 用户/AI 气泡 + 代码块        │ 文件树（虚拟滚动）│
│ 新建会话  │  · 工具调用条 + 操作          │                │
│ 工作区    │ 输入框（上下文 chips 主输入）   │ 分支/改动数      │
└──────────┴──────────────────────────────┴────────────────┘
```

- 左栏固定 230px（会话导航），右栏固定 300px（文件），中栏弹性且最宽。
- **中栏是产品核心**：对话流最大宽度 760px 居中排版，阅读舒适；输入框同样是主操作入口。
- 编辑器不再常驻中栏——当需要看代码时，从右侧文件树打开文件，以"中栏下方分屏/浮层"或切到编辑视图呈现（M1 细化）。对话始终是主视图。
- 三栏分隔线可拖拽（GPUI Dock 布局）。

### GPUI Kit 映射
- 整体用 `gpui-kit` 的 **Dock** 组件：左（会话）/ 中（对话）/ 右（文件）三个 panel。
- 中栏对话流用 **虚拟列表**（长会话性能）；气泡是自绘组件。
- 右栏文件树用 GPUI Kit **Tree** 组件（虚拟滚动）。
- 编辑器用 GPUI Kit **Code Editor**（tree-sitter 高亮 + LSP），按需打开。

## 5. 交互要点

- **模式切换**：恢复上次该模式下的会话。
- **上下文注入**：拖文件/选中文本 → chip；`@` 引用文件、`/` 命令。
- **流式**：逐字增量；可停止。
- **多 Agent**：一条消息可触发工作流；Agent 间自动 handoff；并行任务并行展示；可手动"继续团队协作"。
- **工具调用**：写文件/执行命令默认需确认；成功后绿条"已应用到 xxx · 归属 Agent"。
- **远程/同步**：连接卡可切换远端；断线有重连态；跨设备会话一致。
- **空状态**：中栏未选会话显示引导；右栏无文件提示"打开文件夹"。

## 7. 实现优先级（与路线图对齐）

| 里程碑 | 落地 UI |
|---|---|
| M0 | 窗口 + 三段布局骨架（Dock）+ 令牌主题 + 工作区连接卡（本地模式） |
| M1 | 文件树 + 编辑器（按需打开）+ 会话列表 |
| M2 | 对话（气泡/代码块/流式/输入框/模型选择） |
| M2.5 | **多 Agent 编排 UI**（自定义角色/身份色/协作流/转交/并行）+ **Agent 团队编辑器** |
| M3 | **远程 Workspace Server 连接**（协议 + 连接卡 + 重连） |
| ~~M3.5~~ | ~~跨设备同步~~ → **第一期不做，后续版本** |
| M4 | 命令面板 + 搜索 + Diff + 终端(可选) |
| M5 | 欢迎页 + 设置页 + Toast + 打包 |
